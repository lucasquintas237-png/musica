MÚSICA - reproductor web con YouTube Music
==========================================

Arrancar
--------
1. Doble clic en iniciar.bat  (o: powershell -ExecutionPolicy Bypass -File serve.ps1)
2. Se abre http://localhost:5500 en el navegador.

Desde el móvil u otro aparato de la misma red
---------------------------------------------
Abre http://NOMBRE-DEL-PC.local:5500 (el servidor muestra la dirección exacta al arrancar).
NUNCA por IP (http://192.168...): YouTube da el error 150 y salta las canciones.
La primera vez, Windows puede preguntar por el cortafuegos: permite "Redes privadas".

Publicarla en internet gratis (Cloudflare Pages, sin tener el PC encendido)
--------------------------------------------------------------------------
La carpeta functions/ contiene el intermediario (lo mismo que hace serve.ps1) como
función de Cloudflare, así que la web funciona sola en los servidores de Cloudflare.

1. Sube los cambios a GitHub (git push) en la rama que vayas a publicar (normalmente main).
2. Entra en https://dash.cloudflare.com (cuenta gratis) > Workers & Pages > Create >
   pestaña Pages > "Connect to Git" y elige el repositorio "musica".
3. Configuración de compilación:
     Production branch:       main
     Framework preset:        None
     Build command:           (vacío)
     Build output directory:  /
4. Pulsa "Save and Deploy". En un minuto tendrás una dirección tipo
   https://musica-xxx.pages.dev  (sirve en el móvil y en cualquier sitio).
Cada "git push" a esa rama vuelve a publicar la web automáticamente.

Si Cloudflare lo creó como Worker (el registro dice "npx wrangler deploy"), también vale:
wrangler.jsonc + worker.js publican la web como Worker con archivos estáticos, usando el
mismo intermediario. El nombre del Worker en el panel debe ser "musica" (o cambia "name"
en wrangler.jsonc para que coincida). .assetsignore deja fuera lo que no es de la web.

Archivos
--------
index.html            estructura y estilos
glass.js              barra Liquid Glass (píldora, lente, refracción, muelles)
m3.js                 color dinámico, fondo de tres capas, barra de progreso ondulada
app.js                reproductor, cola, biblioteca, pantalla de inicio
features.js           letras, radio, cola, temporizador, atajos, buscador, artista/álbum,
                      estadísticas, exportar/importar, tema
sources.js            enlaces, listas de Spotify/YouTube Music, errores de reproducción
serve.ps1             servidor local + proxys (YouTube Music, LRCLIB, Spotify, portadas)
functions/api/        los mismos proxys para Cloudflare Pages (web publicada)
worker.js, wrangler.jsonc, .assetsignore   la misma web como Worker de Cloudflare
liquid.js, now.js, fx.js   cristal de la barra, panel "Ahora suena", efectos de Android
sw.js, manifest.webmanifest, icon*.png/svg   app instalable (PWA, solo en localhost)

Tus datos (favoritas, listas, historial) se guardan en el navegador.
Usa Configuración > Exportar datos para hacer una copia.
